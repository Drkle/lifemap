# Informe de avance para revisión del profesor

Abrir **informe_avance.pdf** (7 páginas). Es un borrador, no una declaración de
cumplimiento total de la entrega final. Incluye resultados E1/E2, riesgo con sus
limitaciones, streaming real, curvas por zona y Power BI validado visualmente por el equipo.

Autores preservados del informe E1: Santiago Villamizar Mejía, Juan Echeverri y
Sebastián Botero. Añadir asignatura/grupo/docente si se requiere en la portada.

Las capturas de Power BI fueron aportadas por el equipo en la conversación. No se
incluye una captura inventada: incorporar la imagen original y conservar el PBIX como
anexo cuando se archive la evidencia final. Este PDF sí incluye curvas propias obtenidas
de la API real, con respuestas completas en el JSON de supervivencia por zonas.

Regeneración del contenido: `python docs/entrega2/generar_informe.py`.
Para exportar nuevamente PDF, abrir el HTML en un navegador e imprimir A4, escala 100%,
sin encabezado/pie del navegador y con fondos. Revisar que conserve siete páginas.

Pendientes declarados: Power BI automático, medición continua de disponibilidad,
diferencia frente al servidor separado requerido y sustentación. Las medianas no
alcanzadas y la limitada capacidad predictiva se conservan explícitamente.
